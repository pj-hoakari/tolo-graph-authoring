# グラフ編集コンテキスト

## 責務

- グラフ（ポイント・ルート・入退出点・種別）の正本保持
- 編集はスタッフ／オーナーが設計時に管理 UI のグラフエディタで行い、完成したグラフ文書を一括登録する
- 観測点とグラフ要素の紐づけを所有
- QR 設置箇所（掲示計画）の定義とグラフ要素への紐づけを所有（URL の発行はゲストコンテキスト）
- グラフはイベント単位（イベント識別子はテナントが正本）
- 下流は参照・消費のみ

## ドメインモデル

| 語 | 英語 | 内容 |
|---|---|---|
| グラフ | Graph | イベント単位の共有カーネルのグラフの正本<br>管理 UI での表示名はルート図 |
| グラフ文書 | Graph Document | グラフエディタが組み立てるグラフの文書（構造・表示名・レイアウトを含む）<br>一括保存の単位であり編集状態の正本<br>要素の識別子はエディタが採番し文書内で一意 |
| グラフ版 | Graph Revision | 編集の版（管理単位はグラフ文書のカーネルとラベルのスナップショット。エディタのレイアウトは含めない）<br>公開時に文書から共有カーネルのグラフを導出<br>下流は現在の版を消費 |
| 外部ポイント | External Point | 会場の外を表す仮想的な点<br>エッジで結んだポイントを入退出点にし、エッジの向きで出入りの向きを表す<br>共有カーネルへは導出しない |
| 観測点グラフ紐づけ | Observation Point Mapping | 観測点をグラフ要素に対応づけ<br>WebRTC で確認して行う |
| QR設置箇所 | QR Location | 掲示計画上の設置箇所（名称・種類・グラフ要素参照）<br>会場設計の一部として本コンテキストが所有<br>URL の発行はゲストコンテキスト |

構造定義（ポイント種別・入退出点・方向属性・容量ヒント）は共有カーネルに準拠する（公開時にグラフ文書から導出）。
入退出点はグラフ文書では外部ポイントとの接続で表し、ポイント種別はそのポイント自身のものを保つ。
ゲート地点もポイントとして設計時にオーサリングする（開閉は運用で扱う）。

## ドメインイベント

| イベント | 英語 | 契機 |
|---|---|---|
| グラフ作成された | GraphCreated | 初回の一括保存でイベントにグラフを新設 |
| グラフ保存された | GraphSaved | グラフ文書の一括保存 |
| 観測点がグラフに紐づけられた | ObservationPointMappedToGraph | 観測点をグラフ要素に対応づけ |
| QR設置箇所が変更された | QrLocationChanged | 設置箇所の追加・編集・削除 |
| グラフ版公開された | GraphRevisionPublished | 下流が消費可能な版に |

## 不変条件

- グラフの正本は本コンテキストが保持し、下流は編集しない
- グラフはイベント単位であり、存在しないイベントIDへは作らない
- 構造定義は共有カーネルに準拠
- 編集はグラフ文書の一括保存として累積し、下流へは現在の版を渡す
- グラフ文書のレイアウト情報（グループとその入れ子・座標・寸法）は表示用途のみで、グラフ構造へ影響させない
- グラフ版はカーネルとラベルだけを版管理する。レイアウトは版の外に置き、レイアウトだけの変更で版を変えない
- 外部ポイントはグループに属さず、外部ポイント同士をエッジで結ばない
- 下流へは編集都合の情報（レイアウト・エディタ固有の表現）を渡さず、消費者に応じて導出したデータを渡す
- 紐づけは存在するポイント／ルートに対してのみ行う（外部ポイントとその接続は対象外）。紐づけが参照する要素をグラフ文書の保存で消さない
- 配置系（観測点紐づけ・QR設置箇所）は同一要素への複数配置を許す（各配置が独立の識別子を持つ）
- 同一要素にカメラ方式の観測点紐づけと QR 設置箇所を併存させない（同じ来場者の二重計上を防ぐ。紐づけ時と QR 設置箇所の追加・付け替え時に検証する）
- ルート途中の配置位置（比率）は表示用途のみで、最適化・スコア算出に影響させない
- イベントアーカイブ時はグラフを保持し、読み取り専用にする
